# Scientific integrity evaluation

Run `scout eval` for packaged deterministic synthetic scenarios, and
`python -m pytest -q` for unit, adversarial, HTTP-mock and integration tests.
The evaluator runs in an isolated temporary archive and reports actual checks.
Its passing result means software integrity rules held on fictional records.
It does not certify theorem truth, live model quality, literature completeness
or novelty. No genuine provider output is substituted by this fixture.
