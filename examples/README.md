# Offline example

The installable resource `research_scout/resources/synthetic-history.md` is an
explicitly fictional three-paper history. `scout import-history` archives it;
`scout demo --output /tmp/scout-proposal.md` runs the full progression and handoff.
See `docs/USAGE.md` for exact commands. Do not interpret the fixture's theorem
statements, reviewers or evidence as genuine literature or scientific validation.
