# Knowledge workspaces

This directory documents the logical archive; real user data lives in the
configurable `scout --workspace PATH` workspace (or `SCOUT_WORKSPACE`).
Canonical JSON records cover papers/versions, topics/families/problems,
bottlenecks, mechanisms/variants/applications, results, claims, evidence,
immutable events, comparisons/assessments, transfers and opportunities.
SQLite indexes can be deleted and rebuilt. Do not commit source PDFs, model
credentials or personal literature caches into the package repository.
